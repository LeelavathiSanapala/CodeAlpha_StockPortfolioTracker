Hangman Game – CodeAlpha Internship

Project Description

This is a simple text-based Hangman Game developed using Python as part of my CodeAlpha internship.

The player has to guess a hidden word one letter at a time. The player can make a maximum of 6 incorrect guesses.

Features

- Uses 5 predefined words.
- Allows the player to guess one letter at a time.
- Displays correctly guessed letters.
- Limits incorrect guesses to 6.
- Displays win or lose messages.

Technologies Used

- Python

Concepts Used

- Random module
- While loop
- If-else statements
- Strings
- Lists
- User input and output

How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the terminal in the project folder.
4. Run the following command:

python hangman.py
