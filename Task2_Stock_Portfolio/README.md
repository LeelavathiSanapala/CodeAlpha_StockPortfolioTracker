# CodeAlpha Internship Tasks

## Task 2: Stock Portfolio Tracker

### Project Description
The Stock Portfolio Tracker is a Python-based application
that helps users manage their stock investments.

Users can add stocks, enter the quantity and price per share,
and view their portfolio with the total investment.

### Features
- Add stock details
- Enter stock name, quantity, and price
- Calculate total investment
- View stock portfolio
- Simple menu-driven interface

### Technologies Used
- Python
- Dictionaries
- Loops
- Conditional Statements
- Functions

### How to Run
1. Open the project in VS Code.
2. Open the terminal.
3. Run the following command:

   python stock_portfolio.py
